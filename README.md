<h1>Aist — Система для добавления консультаций в учебное расписание</h1>
Удобный инструмент для преподавателей: загружает расписание из .xls, .xlsx или .txt, позволяет визуально добавлять консультации и сохранять результат в .doc и .json.
<h2>Основные возможности</h2>
<ul>
  <li>Загрузка расписания из файлов .xls, .xlsx или .txt</li>
  <li>Визуальное отображение расписания по дням недели и часам</li>
  <li>Добавление консультаций в свободные слоты (кнопка «Добавить...»)</li>
  <li>Поддержка нескольких файлов расписания (для случаев, когда расписание разделено на несколько документов)</li>
  <li>Гибкие настройки:</li>
  <ul>
    <li>Выбор места сохранения .json файла (вместе с .doc или по указанному пути)</li>
    <li>Формат визуализации: «Исходный» или «Недельный» (с возможностью добавления консультаций на выходных)</li>
  </ul>
  <li>Сохранение результата в двух форматах:</li>
  <ul>
    <li>.doc — полное расписание с консультациями (готов к печати)</li>
    <li>.doc — список консультаций (готов к печати)</li>
    <li>.json — структурированные данные для дальнейшей обработки или интеграции</li>
  </ul>
</ul>
